1. Les Variables

Une variable permet de stocker des informations sous un nom. En Python, pas besoin de spécifier le type, Python le devine tout seul.

# Déclaration de variables
pseudo = "GamerPro"
age = 18
taille = 1.75
est_connecte = True

# Afficher les valeurs
print(pseudo)
print(age)

💪 Exercice pratique :

Crée une variable prenom avec ton prénom et une variable annee_naissance, puis affiche-les.

prenom = "Alex"
annee_naissance = 2005
print(prenom, annee_naissance)

2. print() & input()

print() affiche des données et input() demande à l'utilisateur de taper une valeur.

# Demander le nom de l'utilisateur
nom = input("Quel est ton nom ? ")

# Afficher un message personnalisé (f-string)
print(f"Bienvenue {nom} sur notre site !")

3. Les Conditions

Les conditions permettent d'exécuter du code uniquement si une règle est vraie.

age = 16

if age >= 18:
    print("Tu es majeur.")
elif age == 16:
    print("Presque majeur !")
else:
    print("Tu es mineur.")

💪 Exercice pratique :

Écris un programme qui vérifie si un nombre est positif, négatif ou égal à zéro.

nombre = -5

if nombre > 0:
    print("Positif")
elif nombre < 0:
    print("Négatif")
else:
    print("Zéro")

4. Les Boucles (for & while)

Utilise la boucle for pour un nombre de fois précis, et while pour répéter tant qu'une condition reste vraie.

# Boucle for de 0 à 4
for i in range(5):
    print(f"Tour numéro {i}")

# Boucle while
compteur = 3
while compteur > 0:
    print(compteur)
    compteur -= 1
