# Mon site

## Publier une mise à jour

1. Ajoute ou remplace les fichiers de ton site dans ce dépôt.
2. Garde la page d'accueil à la racine et nomme-la `index.html`.
3. Enregistre les modifications sur la branche `main`.
4. Vercel détectera le changement et publiera automatiquement le site.

Pour un site HTML/CSS/JavaScript classique, aucun build ni commande d'installation n'est nécessaire.
