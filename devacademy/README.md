# DevAcademy

Site vitrine de DevAcademy, hébergé avec GitHub Pages.

## Fichiers
- `index.html` : structure de la page
- `style.css` : design responsive violet et sombre
- `script.js` : petites interactions côté navigateur

## Publication
Le dossier est prévu pour être publié à l'adresse :
https://trixio-code.github.io/devacademy/

## À savoir
GitHub Pages héberge uniquement des fichiers statiques. Les comptes, mots de passe, rôles administrateur, cours enregistrés et classements nécessitent un service backend et une base de données (par exemple Supabase). Ne stocke jamais de mots de passe ou de clés secrètes dans les fichiers publics du site.
